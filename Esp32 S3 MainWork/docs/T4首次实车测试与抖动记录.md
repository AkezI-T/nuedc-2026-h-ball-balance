# T4 首次实车测试与抖动记录

记录日期：2026-07-31

> 本文是当时状态的实测记录，其中提到的代码行为随后已变更；当前实现以各子工程 README 与源码为准。

## 测试结果

T4 整体通信和控制链路已经跑通：

- TMX执行A点到B点降速循迹。
- ESP32进入 `TRACK`，固定目标为O点 `0 mm`。
- TMX在 `lapEnc=2700`时锁存通过B点。
- 最终正常发送 `TASK_END`，未发生ESP32重启或PREP交接失能。

本次B点锁存时间为 `8260 ms`，比题目要求的 `8 s`上限慢 `260 ms`。

## 抖动与滚球误差

滚球控制误差范围为 `-162~+100 px`，只有约 `21.4%`的运行采样位于题目允许的 `±27 px`范围内。

运行期间出现两次 `DRIVE -> BRAKE -> DAMP`控制循环，并发生约8次微步方向切换。实际观察到的抖动主要来自滚球控制，不是底盘循迹：底盘52条采样中有39条完全居中，12条仅有轻微偏差。

当前T4直接复用T3的固定角度控制参数：

- 普通DRIVE角度为 `29 count`。
- 进展不足时提升到 `37 count`。
- DAMP阶段以最高 `50 Hz`追踪较小的编码器角度变化。

对于行驶过程中持续出现的小扰动，上述DRIVE角度偏大，容易造成明显过冲；DAMP对小角度的反复跟踪会产生细碎机械抖动。
